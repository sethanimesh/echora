# Local GazeFollower trial

GazeFollower 1.0.2's bundled MGazeNet model runs through MNN 3.6.1 on the Mac CPU. Use the isolated Python 3.11 environment and requirements.lock. Original MediaPipe 0.10.10 failed graph initialization here; MediaPipe 0.10.21 works. The audio backend environment is unchanged.

The neural model returns 258 features. This experiment uses an application-owned StandardScaler + Ridge(alpha=10) calibration on those features (not the upstream SVR calibration). It collects five examples per target over nine targets and tests four held-out tile fixations before allowing selection. Real accuracy is not yet established. Browser frames travel only to the local loopback service and are not saved. Features and calibration live in memory; stop invalidates the session. The native service does not open a camera itself. This is not a cloud inference endpoint.

`ECHORA_GAZE_ENABLED=true ./scripts/dev.sh` from the repository root starts the optional gaze service on 8767 using the root `.venv-gaze` environment. The existing environment is preserved on this Mac; for a fresh setup, create it with Python 3.11 and install `communication/experiments/gazefollower/requirements.lock` using its Python module entry point (`.venv-gaze/bin/python -m pip`). The frontend proxies `/gaze-api` to it. Open Accessibility → Eye gaze · GazeFollower for the trial. Stop camera / Exit gaze trial closes capture. The earlier WebGazer experiment remains separately selectable.

On macOS, preserve the complete environment when copying it: MNN's native libraries live at `.venv-gaze/lib/libMNN.dylib` and `.venv-gaze/lib/libMNNConvertDeps.dylib`, outside `site-packages`. Both are present in this canonical environment. The extension resolves them using a relative library path; no sibling project or `DYLD_LIBRARY_PATH` is required. A missing `@rpath/libMNN.dylib` error means those environment files are absent.

Checks: `.venv-gaze/bin/python communication/experiments/gazefollower/check_runtime.py` runs random synthetic tensors without camera access (5.73 ms median inference in the canonical environment on this Mac, 258 finite features, changing outputs, no-face rejection). It needs desktop display metadata access because the upstream package initializes display information during import. `check_service.py` passed through the running web app on port 3000, checking its accepted origin, foreign-origin rejection, required request header, blank/invalid frames, calibration shape/balance and stopped-session rejection. Neither check measures real gaze accuracy.
